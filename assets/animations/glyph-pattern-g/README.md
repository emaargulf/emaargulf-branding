This folder will contain an animated draw-on version of the `pattern-g` bracket motif —
the brand's angular bracket pattern rendered as a single animated SVG path, suitable
for loaders, splash screens, and decorative section dividers.

**Planned files:**

| File | Description |
|------|-------------|
| `glyph-pattern-g.svg` | Static bracket glyph |
| `glyph-pattern-g-animated.svg` | Draw-on animation · `currentColor` |
| `glyph-pattern-g-animated-gold.svg` | Draw-on animation · `#F1AA27` |
| `glyph-pattern-g.jsx` | React component |
| `glyph-pattern-g-animated.jsx` | Animated React component |
| `glyph-pattern-g-animation.css` | CSS animation class |
